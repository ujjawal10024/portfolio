# 🚀 Ujjawal Shakya – Personal Tech Portfolio

A modern, responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my skills, projects, and contact information.

🔗 **Live Website:**  
👉 https://ujjawal10024.github.io/portfolio/  

---

## 📌 Project Overview

This portfolio is designed as a single-page responsive website that highlights:

- About Me section
- Skills & Technologies
- AI & Web Projects
- Contact Information
- Resume download option

It serves as a personal brand website and professional showcase for internships and software engineering opportunities.

---

## 🛠 Tech Stack

- **HTML5** – Website structure  
- **CSS3** – Styling, layout, responsiveness  
- **JavaScript (Vanilla JS)** – Interactivity  
- **IntersectionObserver API** – Scroll animations  
- **Media Queries** – Mobile responsiveness  
- **GitHub Pages** – Deployment  

---

## ✨ Features

✔ Fully Responsive Design  
✔ Custom Cursor (Desktop Only)  
✔ Scroll Reveal Animations  
✔ Mobile Hamburger Navigation  
✔ Project Cards with Hover Effects  
✔ Resume Download Button  
✔ Live Demo Links for Projects
