## 📌 Project Overview

This portfolio is designed as a single-page responsive website that highlights:

- About Me section
- Skills & Technologies
- AI & Web Projects
- Contact Information
- Resume download option

It serves as a personal brand website and professional showcase for internships and software engineering opportunities.

## 🛠 Tech Stack

- **HTML5** – Website structure  
- **CSS3** – Styling, layout, responsiveness  
- **JavaScript (Vanilla JS)** – Interactivity  
- **IntersectionObserver API** – Scroll animations  
- **Media Queries** – Mobile responsiveness  
- **GitHub Pages** – Deployment
